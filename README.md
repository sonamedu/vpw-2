# ECI – Election Conducting Institute 🇮🇳

ECI is an advanced, multi-role, gamified simulation platform that models the functioning of a democratic system, with a focus on the Indian election ecosystem.

## 📌 Project Overview
Instead of passive learning, users step into roles like voter, candidate, media, judiciary, or law enforcement and navigate real election scenarios—from campaigning under the Model Code of Conduct to handling misinformation, complaints, and voting-day security. Every decision dynamically impacts system metrics like fairness, trust, and law & order.

## 🚀 Key Features
- **Multi-Role Interaction**: 8 distinct roles with unique responsibilities and decision paths.
- **Demo Login System**: 35 predefined accounts across all roles for immediate simulation.
- **Dynamic Metrics Engine**: Tracks Fairness, Trust Index, Information Integrity, Voter Awareness, and Law & Order.
- **MCC Enforcement**: Real-time detection of bribery, hate speech, and misuse of power during the campaigning stage.
- **Role Switcher**: Seamlessly switch between roles to experience the election from different perspectives.
- **Gamified Progress**: Earn XP and unlock titles like "Informed Voter" or "Democracy Defender".
- **Live Event Feed**: Real-time updates on system-wide election events.

## 🎭 Playable Roles
- **Voters**: Navigate registration and polling while resisting misinformation.
- **Candidates**: Manage campaigns under the strict Model Code of Conduct.
- **Media**: Influence public opinion with real, biased, or fake news.
- **Judiciary**: Adjudicate election disputes and resolve complaints.
- **Police & Central Forces**: Secure polling stations and prevent booth capturing.
- **Admin (BLO/DEO/CEO)**: Oversee the technical and administrative execution of the election.
- **CEC**: The highest authority, making final calls on critical system events.

## 🛠️ Technology Stack
- **Frontend**: HTML5, Vanilla CSS, Javascript.
- **Design**: Premium glassmorphism UI with a tricolor-inspired aesthetic.
- **Simulation**: Custom state engine for handling cross-role dynamics and metric shifts.

## 📂 Project Structure
- `index.html`: Main application shell and UI screens.
- `style.css`: Design system and layout styling.
- `app.js`: Core simulation logic, state management, and interaction engine.
- `scenarios.js`: Data repository for role-specific scenarios and decision impacts.
